Hi — a quick note on today's session.

We worked on the 3 times table using groups of counters. The big win: when we
put four groups of three on the desk, Sparks counted them in jumps without any
prompting — "3, 6, 9, 12!" — and that instant confidence is exactly the building
block the rest of the table sits on.

Where it is still settling: there is a tendency to write an answer before the
counting is finished, so we are practising "lay the groups, count out loud, then
pick up the pencil." That is a new habit and takes a few sessions to stick — it
is completely normal at this stage.

Next time we will open with a quick choral jump-count together, then work through
3×6 to 3×10 with the counters, building on today's confidence.

A lovely moment today: once the counters were on the table and the counting started
out loud, there was real energy and momentum. That is there to build on every session.
