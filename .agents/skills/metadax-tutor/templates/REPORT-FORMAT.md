# Report format — the parent report a tutor sends

A parent report is a short note a tutor sends after a session. It is built from the
tutor's own session notes and the debrief they just ran. This is a way to write it,
never the only way.

It describes **behaviour and nothing more**: what the learner did, what worked, where
they are still working on something. It never diagnoses, never labels the learner,
never uses a real name, school or anything identifying. MetaDAX is free.

---

## The report

Fill from the tutor's debrief. Skip any line you do not have.

```
Hi — a quick note on today's session.

We worked on <topic>. The big win: <what worked or clicked, in plain warm words>.

Where it is still settling: <the main stuck point, as behaviour and gently —
"we are still getting used to <X>", never a label>.

Next time we will <the one next step>.

<One encouraging line about a good moment, if there was one.>
```

### Worked example (multiplication — 3× table)

```
Hi — a quick note on today's session.

We worked on the 3 times table using groups of counters. The big win: counting
in jumps — "3, 6, 9, 12" — clicked straight away once the counters were on the
table. That is the foundation the rest of the table builds on.

Where it is still settling: there is a tendency to write the answer before the
counting is done, so we are practising "count first, pencil second." That is a
new habit and it takes a few sessions to stick.

Next time we will pick up at 3×6 and work through to 3×10, building on that
jump-counting confidence.

A lovely moment today: once we started counting out loud together, there was
real energy — that momentum is there to build on.
```

---

## What the report does NOT do

- No "has trouble with", "struggles with", "is behind" or any label.
- No diagnosis, disorder, condition or syndrome — not even implied.
- No invented score, grade, level or percentage the notes did not give.
- No vendor name, tool name or AI reference.
- No identifying detail beyond what the parent already knows (nickname or "the learner").

---

## The four parts — all required

| Part | What it is |
|---|---|
| What we covered | One or two plain sentences on the topic and how far you got. |
| The big win | The thing that worked or clicked. Build the next session on this. |
| Where it is still settling | The one main stuck point, as behaviour, gently — not a label. |
| Next time we will | Exactly one next step — concrete enough that the parent knows what to expect. |

The encouraging line (a good moment) is optional but almost always worth including.

---

## Length and voice

Under 250 words. Warm, plain, in the tutor's own register — not a template voice,
not a clinical voice. Read it aloud before you send it: if it sounds like you wrote
it, it is ready. If it sounds like a form, rewrite it.

Use the checker at `tools/check-report.mjs` before sending: word count, banned words
(diagnosis terms, vendor names, email patterns).
