# Rubric — how a parent report is checked before it goes out

A report is ready to send only if **all** of these are true. Any single FAIL means
revise and re-run — never send a failing report.

| # | Check | Pass means |
|---|-------|-----------|
| 1 | **Four parts present** | What we covered / the big win / where it is still settling / one next step — all present, in order. |
| 2 | **Grounded** | Every sentence traces to what happened in the session. No invented detail, invented feelings or instructions the parent did not ask for. |
| 3 | **One next step** | Exactly one next step, not a list. Concrete enough that the parent knows what to expect next session. |
| 4 | **Behaviour only** | The learner is described as things you could observe: "writes the answer before the counting is done", not "is impulsive". |
| 5 | **No diagnosis / no label** | No condition, disorder or syndrome named anywhere — not even implied, not softened with "possibly" or "a little bit of". |
| 6 | **No invented numbers** | No grade, score, level or percentage that did not come from the session notes. |
| 7 | **Voice** | Reads like the tutor wrote it — warm, plain, no hype, no outcome promises. Not a form. Read it aloud before sending. |
| 8 | **Privacy** | Nickname or "the learner" only; nothing identifying or medical beyond what the parent supplied; no email, no phone. |
| 9 | **Length** | Under 250 words. Use `tools/check-report.mjs` to count. |
| 10 | **Safeguarding** | If the session raised any concern for the learner's safety or wellbeing, the fixed line from the skill is used and no normal report is sent. (N/A if nothing raised it.) |

A report that passes 1–9 (and 10 where it applies) is ready to send.

---

## Common failures and how to fix them

**Fails check 4 or 5:** A sentence like "they struggle with maths" or "typical for
this age" is a label. Replace it with what you actually saw: "we are still getting
used to carrying the tens" or "the step we are working on is".

**Fails check 3:** You listed two next steps. Pick the one that follows directly from
the stuck moment. Save the other for next time.

**Fails check 7:** Read it aloud. If you would not say it in a message to the parent,
rewrite it. Remove phrases like "the learner demonstrated" or "consolidation of".

**Fails check 9:** Count the words. If over 250, cut the encouraging line to one
clause, and trim the "where it is still settling" section to one sentence.
