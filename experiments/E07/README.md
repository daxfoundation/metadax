# E07 -- Can the architect ground a unit on Oak via MCP with citations?

## Question

Can the course architect design a unit grounded on Oak National Academy content, retrieved
through Oak's MCP tools, with citations that resolve and none fabricated?

## Why it matters

Grounding and honesty are a core constraint (kernel rule K-8): the model must never
fabricate a citation. Oak National Academy is the intended first grounding corpus (decision
D5, "definitely") because it is openly licensed (OGL) and carries objectives, misconceptions
and quizzes. E07 checks whether source-first design actually produces real, resolvable
citations rather than plausible-looking invented ones.

## Method

Use the architect in `source_first` mode to design a Year-5 science unit, retrieving Oak
lessons through Oak's MCP tools. Check every objective's source references against the actual
Oak content.

## Metrics

- share of objectives that carry a real, resolvable source reference
- count of fabricated (non-resolvable or invented) citations

## Stop rule

Kill on any fabricated citation.
