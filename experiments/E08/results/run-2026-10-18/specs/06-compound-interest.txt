SPEC: Compound Interest Table

Export a named ES-module function:

  export function compoundTable(principal, annualRate, compoundsPerYear, years)

Parameters
  principal        – starting amount (number > 0)
  annualRate       – annual interest rate as a decimal (e.g. 0.05 for 5 %)
  compoundsPerYear – number of compounding periods per year (positive integer)
  years            – number of years to compute (positive integer)

Returns an array of length `years`, one object per year:
  {
    year:           number,   // 1-indexed
    balance:        number,   // balance at end of this year, rounded to 2 d.p.
    interest_earned: number,  // interest earned in this year, rounded to 2 d.p.
    total_interest: number    // cumulative interest since start, rounded to 2 d.p.
  }

Formula
  Balance at end of year t:
    A(t) = principal × (1 + annualRate / compoundsPerYear) ^ (compoundsPerYear × t)

Examples
  compoundTable(1000, 0.05, 1, 3)
  → [
      { year:1, balance:1050.00, interest_earned:50.00,  total_interest:50.00  },
      { year:2, balance:1102.50, interest_earned:52.50,  total_interest:102.50 },
      { year:3, balance:1157.63, interest_earned:55.13,  total_interest:157.63 }
    ]

  compoundTable(1000, 0.10, 12, 1)
  → [ { year:1, balance:1104.71, interest_earned:104.71, total_interest:104.71 } ]

  compoundTable(1000, 0, 1, 2)
  → [
      { year:1, balance:1000.00, interest_earned:0.00, total_interest:0.00 },
      { year:2, balance:1000.00, interest_earned:0.00, total_interest:0.00 }
    ]
