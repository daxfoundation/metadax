# E13 Prompt Forge — 2026-10-19 run 2

## Question

Can a sonnet-generated Charlotte Mason variant of MP-06 (the adaptive tutor) keep
MP-06's contract and output schema unchanged while replacing the intro turn with a
narration-invitation (learner retells in their own words, Charlotte Mason style), and
can that variant then pass certification?

## What changed since run 1

Run 1 (SIMULATED) passed structural certification using a retrieval-practice-first variant (display.message
must contain "retrieval" or "recall") — not the Charlotte Mason variant the E13 card names.
Run 2 generates and certifies the card's stated variant: Charlotte Mason style, with a narration
invitation ("in your own words" / "narrate" language) replacing the intro turn (not added alongside it).

## What ran

- **Model:** claude-sonnet-4-6 (SIMULATED — sonnet agents acting as the MetaDAX engine)
- **n:** 1 run per case (no seeds; temperature not set)
- **Cases:** 6 MP-06 base cases × CM variant stack + 4 new MP-06-cm cases × CM variant stack = 10 runs
- **Grader:** `/tmp/metadax/evals/grade.js` (schema + expect) + `check-cm-behavior.cjs` (CM narration language + type + state checks for the 4 new cases)
- **Sizes:** stacks ~330–380 lines; outputs 1–3 KB each
- **CM §1 generation method:** direct model prompting — one sonnet agent given the base §1 and retrieval-first §1 as reference, plus plain-language CM instruction (no FORGE prompt; FORGE does not yet exist)

## Verdict vs the card's kill line

**INCONCLUSIVE (SIMULATED).** Schema-valid 10/10 and shows the method's surface features; fidelity to the method is unverified because the card's reviewer check was not run.

The PASS rests on schema validity plus a word-list check for phrases the prompt itself instructs ("in your own words", "narrate", etc.), which is circular — a model following the CM §1 wording will automatically produce those phrases. The card requires a reviewer familiar with the Charlotte Mason method to judge whether the output is educationally faithful; that check was not run. Kill line not reached (kill = fails certification twice after repair), but the key fidelity gate is missing.

Note: n=1 per case, with no seed or temperature setting. The base prompt's 7/10 vs the CM variant's 10/10 schema-valid is likely noise from an enum failure (`in_progress`) in the base prompt, not a meaningful quality signal from the variant.

Run 1 passed structural checks with a substituted variant (retrieval-first); run 2 confirms the card's actual variant (CM/narration) also passes structural checks, with identical counts.

## What compounds

- Both the retrieval-first variant (run 1) and the Charlotte Mason variant (run 2) pass
  certification from a single generation pass with no hand edits. Two independent method-variants
  of the same base prompt both pass, strengthening the Prompt Forge viability case.
- The CM check word list ("in your own words", "narrate", etc.) is broader than the retrieval
  check ("retrieval", "recall") because CM narration language has more surface forms; the CM
  variant still passes all 4 behaviour checks, suggesting the CM §1 wording is unambiguous
  enough that a model follows it reliably.
- The same 3-file pattern (stack substitution → case stacks → check script) used in run 1
  reproduced cleanly in run 2, suggesting it is a reusable certification harness.

## Dead ends kept

- **FORGE operation absent:** same as run 1 (B46). CM §1 was generated by direct prompting;
  regeneration is not reproducible from a formal schema.
- **Narrow new-case coverage:** same as run 1 (B47). Four cases cover fresh-start (no progress),
  fresh-start (partial progress), narration-answered-correctly, and resume. Narration answered
  wrongly, narration skipped, multi-concept narration order, and narration at concept 2+ are untested.
- **Completed-first-concept edge case:** same as run 1 (B48). CM §1 does not specify what to
  do if the first concept's Remember level is already passed.
- **Method-literate reviewer not run:** the card calls for a reviewer familiar with the Charlotte
  Mason method to judge the output. This run is SIMULATED; no such review was performed. The
  CM behaviour checks are a proxy only.
