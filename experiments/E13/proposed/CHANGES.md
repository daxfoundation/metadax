# Proposed changes — E13 Prompt Forge

## prompts/MP-06-variants/retrieval-first.md

**Why:** E13 generated a retrieval-practice-first variant of MP-06 (the adaptive tutor).
The original MP-06 greets the learner with an intro turn and then asks the first question.
This variant replaces the intro turn with a retrieval-probe question (type `question`,
not `intro`), where the learner is asked to freely recall what they already know about the
first concept before the quiz begins. The probe uses `question_type` "Short Answer (explain
in own words)", bloom_level Remember, and its `display.message` MUST contain the word
"retrieval" or "recall".

After the probe is answered (right, wrong, or skipped), the quiz continues normally from §4
(grading and attempts) as if the probe were a standard Remember-level question. There is no
deferred intro and no special scoring beyond the normal rules.

**Contract and schema:** unchanged from MP-06. All output types, state fields, competency
formula, command set, and the `tutor-turn/0.2` schema are identical. The only behavioural
difference is the first turn: `question` instead of `intro`.

**Generation method:** SIMULATED — the variant was generated by a sonnet agent given the
original MP-06 prompt text and an instruction to add retrieval-practice-first behaviour while
keeping the contract and output schema unchanged.

**No hand edits after generation.**

### prompts/MP-06-variants/charlotte-mason.md (proposed)

**Why:** E13 run 2 generated and certified the Charlotte Mason variant the experiment card
originally specified. Charlotte Mason method principles applied: short lessons, narration
in the learner's own words, warm living-book language, no worksheets.

The variant replaces the intro turn with a narration invitation (type `question`, bloom_level
Remember), where the learner is asked to retell what they already know about the first concept
as if explaining it to a friend. The `display.message` MUST contain the phrase "in your own
words" or the word "narrate" or "narration". Framing is warm, not textbook-dry.

On SESSION resume: the variant continues from the established state and does NOT re-narrate.

After the narration is answered (right, wrong, or skipped), the quiz continues normally from
§4 onward. No deferred intro; no special scoring beyond the normal rules.

**Contract and schema:** unchanged from MP-06. All output types, state fields, competency
formula, command set, and the `tutor-turn/0.2` schema are identical.

**Generation method:** SIMULATED — §1 generated by a sonnet agent given the base §1 and
retrieval-first §1 as reference, plus a plain-language instruction to apply Charlotte Mason
narration principles. No FORGE operation used (FORGE does not yet exist).

**No hand edits after generation.**

**Certification:** 10/10 schema-valid, 4/4 CM behaviour checks, 0 failures (run 2, 2026-10-18).
