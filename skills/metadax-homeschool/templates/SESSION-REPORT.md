# Session report — for the guide, built from the next-time note

A session report turns the end-of-session next-time note (see `LOOP-PLAIN-CHAT.md`)
into a short, readable record a guide can keep or share. It is built from the same
five things the note carries: what happened, what worked, misconceptions seen, and
the next step. This is a way to write it up, never the only way.

It describes **behaviour and nothing more**. It never diagnoses, never labels the
learner, never uses a real name, school, date or anything identifying. A nickname
or "the learner" only. MetaDAX is free.

---

## The report — guide-facing

Fill from the next-time note; skip any line you don't have.

```
MetaDAX session report
Ref: <short code, or blank>    ·    Session: <which one>

What we did
  <one or two plain lines: the topic worked on and how far we got>

What worked
  <the idea or moment that landed — build the next session on this>

What tripped us up
  <the slips seen, as behaviour, each with a rough count — never a label:
   "added the tops and bottoms together x3", not "struggles with fractions">

Next step
  <the one thing to move on next time — one step, aimed at what tripped us up>

A good moment
  <optional: something only a person saw or did — worth keeping>
```

### Worked example (the hockey/fractions session from `LOOP-PLAIN-CHAT.md`)

```
MetaDAX session report
Ref: HS-7HKY    ·    Session: 1

What we did
  Added fractions with the same bottom number, and tried a few with different
  bottom numbers.

What worked
  Equal parts clicked using a hockey rink cut into equal zones — "halves have to
  be the same size" landed.

What tripped us up
  Added the tops and the bottoms separately (1/2 + 1/3 came out as 2/5) x3. Said a
  bigger bottom number means a bigger fraction x2.

Next step
  Show why you can't add the bottoms — cut the rink two ways and line them up —
  then one gentle set of unlike-denominator adds. Keep it short.

A good moment
  Went quiet after a wrong answer, then came back when they got to explain the
  power-play setup first.
```

## Short variant — for a tutor to send a parent

Warmer, shorter, strengths first. Same rule: behaviour only, no diagnosis, no
label, no identifying detail. A tutor sends this; a classroom teacher or trainer
would adapt the "you"/"your child" wording for their audience.

```
Hi — a quick note on today's session.

We worked on <topic>. The big win: <what worked, in plain warm words>.

Where it's still settling: <the slip, as behaviour and gently — "we're still
getting used to <X>", never a label>.

Next time we'll <the one next step>.

<One encouraging line about a good moment, if there was one.>
```

### Worked example (parent variant)

```
Hi — a quick note on today's session.

We worked on adding fractions. The big win: picturing a hockey rink cut into equal
zones made "equal parts" really click — that's the foundation everything else sits
on.

Where it's still settling: when the bottom numbers differ, we're still getting used
to why you can't just add them together. That's a normal next hurdle.

Next time we'll show that with the rink cut two ways, then try a few gentle ones.

Lovely moment today: they taught me how a power play is set up — explaining it out
loud clearly helped them focus.
```

Note what both versions do **not** do: no "has trouble with", no "is behind", no
"struggles with maths", no guess at why. Just what happened, what worked, what to
do next.
