# The next-time loop in any AI chat — one page to print

You do not need any skill installed to carry MetaDAX from one session to the next.
Any AI chat will do. The trick is a short **next-time note** you write at the end of
each session and paste at the start of the next. This is a way to keep the thread,
never the only way.

How it works: you run a session with the learner → at the end you jot the note
below → **nothing leaves the device unless you copy it** → next time you paste
"Here is my MetaDAX next-time note from last session, build the next one" and the
note itself. Every rule the chat needs to continue is written into the note, so any
frontier chat can pick up where you left off.

MetaDAX is free.

---

## The next-time note — what to write

Keep it to one screen. Fill in what you saw; skip what you didn't. Use a nickname
or "the learner" — **never a real name, school, age-as-birthday, or anything
identifying.**

```
MetaDAX next-time note
Ref: <the short code from the session, e.g. HS-4KQ2 — or leave blank>
Session: <which one, e.g. 2>

What the learner did:   <what they worked on; how far they got>
What worked:            <what landed — the idea or the moment that clicked>
Misconceptions seen:    <the slips, each with a rough count, e.g. "...  x3">
The trail (what I saw): <how they behaved — went quiet, raced ahead, asked to
                         teach me the game>
Interests:              <the theme used; whether it still lands or they're bored
                         of it>
Only I could:           <the one thing only a person did — a hug, a real example,
                         backing off>
Stopped:                <did you finish, or stop early and where>
```

## The four rules that keep it short — tell the chat to follow these

1. **Keep what worked.** Open the next session with a callback to what landed. Build
   on it; never reset to the start.
2. **Move one step.** Advance exactly on the misconceptions seen — one step, not
   five — and never repeat what already failed the same way.
3. **Swap the theme on boredom.** If the note says they tired of the theme, pick a
   fresh interest and rebuild the examples through it. If it still lands, keep it.
4. **Pace to the ending.** If the last session ran long or stopped early, make the
   next one shorter and gentler; if they raced through, give more.

Rules that keep the note itself short: one screen, nickname only, behaviour not
labels, a rough count on each slip, no dates — say "session 2", not a date.

## A worked note — an 11-year-old who loves hockey, stuck on fractions

```
MetaDAX next-time note
Ref: HS-7HKY
Session: 1

What the learner did:   Added fractions with the same bottom number; tried a few
                        with different bottom numbers.
What worked:            The equal-parts idea landed when we cut a hockey rink into
                        equal zones — "halves have to be the same size" clicked.
Misconceptions seen:    Added the tops and the bottoms separately (1/2 + 1/3 = 2/5)
                        x3.  Said a bigger bottom number means a bigger fraction x2.
The trail (what I saw): Lit up at the rink example; went quiet after the first
                        wrong answer, came back when I let them explain the zones to
                        me.
Interests:              Hockey — still landing hard, keep it.
Only I could:           Noticed the quiet and backed off, let them teach me the
                        power-play setup before we tried again.
Stopped:                Finished, but the last two were a stretch — keep next
                        session short.
```

**What the next session should do with this note:** open by recalling that
equal-sized zones clicked (rule 1); take one step onto unlike denominators by
showing why you can't add the bottoms — cut the rink two ways and line them up
(rule 2, aimed straight at the 2/5 slip); keep hockey (rule 3 — it's still
landing); and keep it short and gentle because the end was a stretch (rule 4).
