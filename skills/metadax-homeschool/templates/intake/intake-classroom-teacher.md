# Intake — the questions to ask, for a classroom teacher

You are a teacher with a class of many learners, usually around the same age. This
is a way to run intake, never the only way. Answer in plain language, in your own
words. About a dozen short questions. Describe the class by **behaviour**, never a
label or a diagnosis of any one child. Ask for nothing identifying — no child's
real name, no school, town, birth date, email or phone. You describe the group, not
a roster.

## The class and the goal

- **Goal** — what do you want this lesson to land? In your words: "they can add
  fractions with unlike denominators", "they can read a graph", "they can write a
  clear topic sentence."
- **How many learners** — roughly how many are in the group? You answer the learner
  questions **once for the class**, not per child.
- **Age** — how old are they (4–18)? One band for the class, or two if it is a
  mixed group: `4-6`, `7-9`, `10-12`, `13-15`, `16-18` (and `4-9` for a wide span).
  The band splits who-does-what.
- **How often you meet** — one lesson, a unit over several lessons, a whole term.
  Pages say "session 1", never a date; the cadence sets how much carries forward.
- **How it runs** — projected on a screen, printed on paper, one device each, or a
  mix. This shapes what the page assumes.

## What the class is working on

- **Stuck on** — where does the class as a whole get stuck? The more exact the
  better ("they add the tops and the bottoms", "they drop the carry").
- **A common wrong answer** — one you see a lot. This tells you more than anything
  else, and it never names a child.
- **Prior knowledge** — what has the class already covered that this builds on?
  What is assumed from earlier in the year?
- **The spread** — a few are ahead, a few are behind, most in the middle? Describe
  it as behaviour ("the fast finishers get restless"), never as labels.
- **Source material** — a curriculum point, a textbook chapter, a standard, a
  worksheet you already use? Paste or name it; the lesson is grounded in it. Leave
  out anything identifying.
- **Already tried** — how have you taught this before, and where did it lose them?

## Interests (these pick the theme)

- **The class loves** — what themes land with this group? Sports, space, animals,
  a game everyone plays. Examples and games are built through these, and swapped
  when they stop landing. One theme for the class is fine.
- **Who can lead** — is there a topic some learners could explain to the rest? This
  becomes the "lead" moment, where a learner is a step ahead.

## You, the teacher

- **This subject for me** — a weak spot / rusty / comfortable / know it well. The
  page is written for where you are.
- **Explain things to me** — short and plain / step by step / with the why / with
  everyday examples.
- **Language** — English, French, both, or other.

If anything typed in looks like an email, phone number, link or an `@handle`, say
what it looks like and leave it out of everything you build.

## What you get back

A single lesson package to run with the whole class: a side for you with the steps,
the tricky spots, and what only a teacher can do; a learner side with games built
through what the class loves, with the age split tagged so you can see at a glance
which part suits which group. At the end the page shows a short next-time note you
copy to carry into the next lesson. Nothing leaves the device unless you copy it.
MetaDAX is free.
