# Licence for this course

Choose one licence for the human-authored course material (lessons, modules,
objectives, teacher notes, and any node text you wrote yourself). Delete the
option you do not pick and set the same SPDX id in `course.json` under
`license`.

- **CC BY 4.0** (`CC-BY-4.0`, the default): others may reuse and adapt with
  attribution.
- **CC BY-SA 4.0** (`CC-BY-SA-4.0`): the same, but adaptations must be shared
  under the same licence.

**Model-generated segments** (text produced by a Meta DAX engine, for example a
follow-up node's `core`) are released under **CC0 1.0** (`CC0-1.0`) and recorded
in `course.json` under `generated_segments_license`. This keeps generated
knowledge freely reusable while your own authored material keeps the licence you
chose above.

This note is documentation. The authoritative values are the SPDX id strings in
`course.json`.
