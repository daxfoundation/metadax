# Share a MetaDAX sample

MetaDAX › [Help](index.md) › Share a sample

If a lesson helped you, a generic version of it can help the next family with the
same stuck spot. Sharing is your choice, it is never automatic, and a person
reviews every one before it appears.

## 1. Make the generic version

Ask the skill (or your AI chat) to make a generic version you could share. It
writes two small files: `sample.md` (the lesson written for another guide) and
`entry.json` (one line for the library index). It invents fresh, made-up names —
not the nickname you used — and strips every identifying detail, keeping only the
teaching.

## 2. Take the names out first

Before you post anything, read it through and confirm:

- made-up names only — no real name, school, town, birth date, email, phone or
  photo;
- no diagnosis or condition named anywhere — the stuck point is described as
  behaviour;
- the "a way, never the way" line is present.

## 3. Post it with the form

Open the **"Share a sample"** form and paste `sample.md` and `entry.json` into the
two boxes, then tick the three confirmations. There is no upload and no account.

[Open the "Share a sample" form →](https://github.com/daxfoundation/metadax/issues/new?template=share-a-sample.yml)

A reviewer reads it, and if it is clear of anything identifying, publishes it into
the library and adds the index line. Then the next parent with the same stuck spot
gets a head start.
